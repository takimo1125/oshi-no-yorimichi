## 概要

機能目的:

- 前の週に公開された写真をまとめて見せ、ほかのファンの記録に出会ってもらう

機能概要:

- 前の週（月曜〜日曜）の公開写真をまとめたギャラリーの表示
- 対象の週の切り替え

関連する機能：C-07、I-07

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 最新の週のギャラリーを表示する |
| 2 | 前の週 | ボタン押下 | 同じ画面で対象の週を切り替える |
| 3 | 写真・ひとこと | 項目押下 | [UIS14](../UIS14/README.md) へ遷移 |

| 5 | みんなの展示を見る | ボタン押下 | [UIS51](../UIS51/README.md) へ遷移 |
| 6 | みんなのよりみちにもどる | リンク押下 | [UIS09](../UIS09/README.md) へ遷移 |

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| week | 対象の週 | 省略したら最新の週。通知から開いたときはその号の週 |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API39 | 指定した週の週刊ギャラリーを取得する | week |

画面表示制御:

- ギャラリーは、毎週月曜 07:00（日本時間）のバッチが前の週の公開写真から作る。画面では作らない
- 表示するときに記録の公開状態を確かめ、非公開になった記録は表示しない

### 2. 前の週

1 つ前の週を `week` にして、イベント 1 と同じ API で取得し直す。いちばん古い週より前に進めない場合の表示は未確定。

### 3. 写真・ひとこと

[UIS14](../UIS14/README.md) へ遷移する。

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| post_id | 押した記録の ID | |

### 補足

週刊ギャラリーは、金曜 19:00 に届く「好きなタグの週末便」（F-03）とは別のもの。
