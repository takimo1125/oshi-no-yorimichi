## 概要

機能目的:

- 推しと過ごした日を、写真とひとこと、または文字だけで記録してもらう

機能概要:

- 写真の追加（1 件の記録に 10 枚まで。写真なしでもよい）
- 日付・記録の種類・ひとこと・タグ・いっしょのグッズの入力
- 公開範囲の選択
- 下書きの保存と投稿

関連する機能：B-01、B-02、B-03、B-05、B-06、B-07

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 新しい記録、または下書きの続きを表示する |
| 2 | 写真を追加 | ボタン押下 | 端末の写真を選び、アップロードする |
| 3 | 写真の × | ボタン押下 | 選んだ写真を記録から外す |
| 4 | タグを追加 | ボタン押下 | [UIS24](../UIS24/README.md)（タグ検索）へ遷移 |
| 5 | いっしょのグッズ | 入力欄押下 | [UIM02](../UIM02/README.md) を起動 |
| 6 | 公開・非公開 | 選択 | 公開範囲を選ぶ |
| 7 | 下書き保存 | ボタン押下 | 下書きとして保存し、[UIS13](../UIS13/README.md) へ遷移 |
| 8 | 投稿する | ボタン押下 | 記録を保存し、[UIS15](../UIS15/README.md) へ遷移 |

## イベント詳細

### Figma の操作と遷移

共通ナビゲーションは [画面共通の動き](../README.md#全画面で共通の動き) を参照。表はリンクが設定された操作を示す。リンクのない操作の処理・未確定事項は後述する。

| 画面モデル | 操作 | 遷移先・状態 | 表示方法 |
| --- | --- | --- | --- |
| 全状態 | タグを追加 | [UIS24](../UIS24/README.md)（`search_tags`） | 画面へ遷移 |
| `post_create_photo` | いっしょのグッズ | [UIM02](../UIM02/README.md)（`goods_picker`） | モーダルを起動 |
| 全状態 | 公開 | 同じ画面で選択した値を表示 | 選択状態の変更 |
| 全状態 | 非公開 | 同じ画面で選択した値を表示 | 選択状態の変更 |

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| draft_id | 続きを書く下書きの ID | [UIS13](../UIS13/README.md) から開いたときだけ渡す |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API26 | 下書きを取得する | draft_id（渡されたときだけ） |

画面表示制御:

- `draft_id` がない新規作成では、日付に今日の日付を入れ、公開範囲は公開・非公開のどちらも選ばない状態で始める
- `draft_id` がある再開では、保存した日付・ひとこと・写真・記録の種類・タグ・グッズ・公開範囲の選択を復元する。新規作成の初期値では上書きしない。保存時に公開範囲が未選択なら、未選択のまま復元する
- 写真がない場合は、文字だけの記録の表示にする（`post_create_text`）。写真を追加したら、写真のある記録の表示にする（`post_create_photo`）
- 写真やグッズは必須にしない
- 下書きの公開範囲の選択を復元しても、下書きを公開したことにはしない。投稿するまでは本人だけが見られる
- 手順外への離脱と保存結果を確認できない場合の扱いは、[離脱の共通仕様](../README.md#未保存の入力と離脱)・[保存の共通仕様](../README.md#保存の結果を確認できないとき) に従う

### 2. 写真を追加

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API24 | 画像 ID とアップロード用の URL を発行する | 選んだ写真の数 |

画面表示制御:

- 発行された URL へ、端末の写真を直接アップロードする
- 1 件の記録に 10 枚まで。10 枚を超える写真は追加できない
- 大きなプレビュー 1 枚と、その下にサムネイルと追加用の枠を並べる
- 一覧用の縮小画像と位置情報などの削除は、アップロードの後にサーバー側で行う（B-07）。画面では待たない

### 4. タグを追加

[UIS24](../UIS24/README.md)（`search_tags`）へ遷移する。タグを選んだら元の作成・編集の画面に戻り、選んだタグを入力欄に足す。入力中の内容はそのまま残す（[共通仕様](../README.md#未保存の入力と離脱)）。

UIS24 を `pick=tag&return_to=<元の画面>` で開き、選んだタグを `picked_tag=<タグ名>` に付けて元の画面へ戻る。入力中の内容は sessionStorage から復元する（[API 設計書の「画面間の入力の受け渡し」](../../07_API設計書/README.md#画面間の入力の受け渡し)）。

### 5. いっしょのグッズ

[UIM02](../UIM02/README.md) を起動する。入力中の内容は保ったまま開く。

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| selected_goods_ids | いま選んでいるグッズの ID | |

戻り値として、選んだグッズの ID を受け取り、「いっしょのグッズ」に表示する。

### 7. 下書き保存

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API27 | 下書きを保存する | 入力フォームの値、画像 ID、draft_id（あれば） |

画面表示制御:

- 保存に成功したら [UIS13](../UIS13/README.md) へ遷移する
- 下書きでは必須の項目を設けない。どの項目も空のまま保存できる

### 8. 投稿する

入力チェック:

| 項目 | チェック |
| --- | --- |
| 写真 | 任意。10 枚まで。1 枚 10MB まで。JPEG・PNG |
| 日付 | 必須 |
| 記録の種類 | 任意。「飾った」「連れていった」「迎えた」「参戦した」から選ぶ |
| ひとこと | 写真がない記録では必須、写真がある記録では任意。300 文字まで |
| タグ | 任意。10 個まで。1 つのタグは 30 文字まで |
| いっしょのグッズ | 任意 |
| 公開範囲 | 公開・非公開のどちらかを選んでいること |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API29 | 記録を保存する | 入力フォームの値、画像 ID、draft_id（あれば） |

画面表示制御:

- 保存に成功したら [UIS15](../UIS15/README.md) へ遷移する
- 下書きから投稿した場合、その下書きは下書き一覧から消す

### 補足

アップロードした後、7 日を過ぎても記録にも保存済みの下書きにも結び付かない画像は、毎晩のバッチで消す（I-04）。
