## 概要

機能目的:

- 契約中の人を、Stripe のカスタマーポータル（契約者向けの管理画面）へ案内する

機能概要:

- カスタマーポータルでできることの案内（契約の内容・支払い情報の変更・請求情報の確認）
- カスタマーポータルへの移動

関連する機能：G-01

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | |
| 2 | Stripeの契約管理画面へ | ボタン押下 | カスタマーポータルへ移動 |
| 3 | 契約情報へ戻る | ボタン押下 | [UIS38](../UIS38/README.md) へ遷移 |

### 1. 初期表示

起動パラメータ：なし

利用API：なし

### 2. Stripeの契約管理画面へ

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API77 | Stripe のカスタマーポータルのセッションを作る | なし |

画面表示制御:

- 作ったセッションの URL へ移動する
- 解約・解約予約の取消し・カードの変更は、カスタマーポータルで行う
- 請求書の閲覧もカスタマーポータルで提供する。自サービスに帳票の一覧・詳細画面は追加しない
- カスタマーポータルから戻ってきたら [UIS42](../UIS42/README.md) を表示する。戻っただけでは、契約の変更や解約が済んだとはみなさない
