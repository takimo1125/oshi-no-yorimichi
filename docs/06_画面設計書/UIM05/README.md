## 概要

機能目的:

- 他の利用者をブロックする直前に、本当にブロックするかを確かめる

機能概要:

- 対象の利用者の表示
- ブロックの実行

関連する機能：D-03

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 対象の利用者を表示する |
| 2 | ブロックする | ボタン押下 | ブロックし、[UIS23](../UIS23/README.md)（`user_posts`）へ遷移 |
| 3 | キャンセル | ボタン押下 | 何もせずにモーダルを閉じる |

### ブロックの効果

- ブロックは双方向に効く。ブロックした人とされた人は、お互いの記録・展示・プロフィール・コメントが見えなくなる。検索・一覧・詳細の直接アクセスでも表示しない
- お互いに、いいね・コメント・フォローができなくなる
- ブロックしたら、お互いのフォローを外す。ブロックを解除しても、フォローは元に戻さない
- ブロックされた側には通知しない
- 解除は、相手のプロフィール（[UIS23](../UIS23/README.md)）と、ブロック・ミュートした人の一覧（[UIS53](../UIS53/README.md)）で行う
