## 概要

機能目的:

- ほかの利用者が公開したテーマ展示を眺めてもらう

機能概要:

- 公開された展示の新着一覧と、フォローしている人の展示の一覧
- 展示の詳細・わたしの展示への導線

関連する機能：E-02

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 公開された展示を新しい順に表示する |
| 2 | 新着・フォロー中 | タブ押下 | 同じ画面で、新着の展示と、フォローしている人の展示を切り替える |
| 3 | 展示の表紙・タイトル | 項目押下 | [UIS29](../UIS29/README.md) へ遷移 |
| 4 | わたしの展示を見る | ボタン押下 | [UIS25](../UIS25/README.md) へ遷移 |
| 5 | みんなのよりみちにもどる | リンク押下 | [UIS09](../UIS09/README.md) へ遷移 |

### 1. 初期表示

起動パラメータ：なし

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API71 | 公開された展示を新しい順に取得する | ページ送りの位置 |

画面表示制御:

- 展示ごとに、表紙・タイトル・作者・記録の件数を表示する
- 非公開の展示は表示しない
- ブロック・ミュートした利用者の展示は表示しない
- 公開された展示が 0 件のときは、「まだ公開された展示はありません。」と表示し、「わたしの展示を見る」への導線を出す（`public_exhibitions_empty`）

### 2. 新着・フォロー中

「フォロー中」では、フォローしている人の公開された展示を新しい順に表示する（`public_exhibitions_following`）。0 件のときは「フォローしている人の展示は、まだありません。」と「新着を見る」を表示する（`public_exhibitions_following_empty`）。ログインを必要とし、未ログインではログインへ案内する。

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API72 | フォローしている利用者の公開された展示を新しい順に取得する | ページ送りの位置 |
