## 概要

機能目的:

- 自分のプロフィールと推しのタグを設定してもらう

機能概要:

- アイコン・表示名・自己紹介の変更
- 推しのタグの追加・削除

関連する機能：A-02

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 保存済みのプロフィールを表示する |
| 2 | 画像を選ぶ | ボタン押下 | 端末の画像を選び、アップロードする |
| 3 | タグを追加 | ボタン押下 | 推しのタグを追加する |
| 4 | 保存する | ボタン押下 | プロフィールを保存し、[UIS23](../UIS23/README.md) へ遷移 |
| 5 | キャンセル | ボタン押下 | 保存せずに [UIS23](../UIS23/README.md) へ遷移 |

## イベント詳細

### Figma の操作と遷移

共通ナビゲーションは [画面共通の動き](../README.md#全画面で共通の動き) を参照。表はリンクが設定された操作を示す。リンクのない操作の処理・未確定事項は後述する。

| 画面モデル | 操作 | 遷移先・状態 | 表示方法 |
| --- | --- | --- | --- |
| 全状態 | 保存する | [UIS23](../UIS23/README.md)（`profile_self`） | 画面へ遷移 |
| 全状態 | キャンセル | [UIS23](../UIS23/README.md)（`profile_self`） | 画面へ遷移 |

### 1. 初期表示

起動パラメータ：なし

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API19 | 本人のプロフィールを取得する | なし |

### 2. 画像を選ぶ

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API24 | 画像 ID とアップロード用の URL を発行する | 1 枚 |

### 4. 保存する

入力チェック:

| 項目 | チェック |
| --- | --- |
| アイコン | 任意 |
| 表示名 | 任意。30 文字まで。空のときはユーザー名を表示する |
| 自己紹介 | 任意。160 文字まで |
| 推しのタグ | 任意。10 個まで。1 つのタグは 30 文字まで |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API20 | 本人のプロフィールを更新する | 入力フォームの値、画像 ID |

画面表示制御:

- 更新に成功したら、本人のページ（[UIS23](../UIS23/README.md)）へ遷移する
- ユーザー名は登録後に変更できない。プロフィールの URL と検索に使うため。この画面で変更できるのは、アイコン・表示名・自己紹介・推しのタグ
