## 概要

機能目的:

- 自分のテーマ展示を一覧で見て、作成・編集してもらう

機能概要:

- 本人の展示の一覧（公開・非公開の両方）
- 展示の作成・編集・閲覧への導線
- 展示プラスの案内への導線

関連する機能：E-01、E-02、E-07、G-01

### 1. 初期表示

起動パラメータ：なし

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API62 | 本人の展示を取得する | なし |
| API75 | 本人の展示プラスの契約の状態と有料権限を取得する | なし |

画面表示制御:

- 展示ごとに、表紙・タイトル・説明・「公開」「非公開」の印を表示する
- 展示が 0 件の場合は「まだ展示がありません。」と、展示の作成への導線を表示する（`exhibitions_empty`）
- 展示プラスの契約が終わった後も、作成済みの展示は表示し、閲覧できる

### 展示数と契約終了後の操作

- 無料で保持できる展示は 1 つ。生涯の作成回数ではなく、現在保持している公開・非公開の展示の合計で判定する
- 有料権限が有効な場合は、複数の展示を新規作成できる。有料時は展示数の上限を設けない。展示は既存の記録を選んで並べるもので、新しく写真を保存しないため
- 有料権限がない場合、現在 0 件なら 1 つ作成でき、1 件以上なら追加作成できない。契約終了後も同じ条件で判定する。既存展示を削除して 0 件になった場合も 1 つ作成できる
- 契約終了後も既存展示は件数にかかわらず保持し、すべて閲覧・編集・公開範囲の変更・削除ができる。1 件を超えた分を自動で削除したり、編集不可にしたりしない
- 削除は、各展示の「削除」から [UIM13](../UIM13/README.md) で確認して行う。契約終了と、本人が操作する削除を区別する
- 有料権限がない人には、「無料では展示を 1 つまで持てます」と、展示プラスにすると複数つくれること、削除すると新しく 1 つつくれることを案内する（`exhibitions_free`）
- 保存容量の上限は、無料・有料とも設けない。写真の量は、1 記録 10 枚までと 1 枚の大きさの上限で抑える（[UIS11](../UIS11/README.md)）

### 2. 展示をつくる

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API75 | 本人の有料権限を取得する | なし |

画面表示制御:

- 現在保持している展示が 1 件以上の場合
  - 有料権限が有効なら、[UIS26](../UIS26/README.md) へ遷移する
  - 有料権限がなければ、[UIM08](../UIM08/README.md) を起動する
  - 申し込みの確認中なら、[UIS40](../UIS40/README.md) へ遷移する
- 現在 0 件の場合は、無料でも [UIS26](../UIS26/README.md) へ遷移する。作成開始時だけでなく、初回保存時にもサーバーで件数と権限を確認し、同時操作で無料上限を超えないようにする

起動パラメータ（[UIM08](../UIM08/README.md) へ渡す）:

| Name | Value | Memo |
| --- | --- | --- |
| feature | `multiple_exhibitions` | 複数の展示 |

### 5. 展示プラスについて
