## 概要

機能目的:

- 利用規約の全文を、誰でも読めるように公開する

機能概要:

- 利用規約の全文の表示
- 目次から各条への移動（PC）

関連する機能：H-05

### 1. 初期表示

起動パラメータ：なし

利用API：なし。本文はリポジトリの Markdown から作り、画面に固定で持つ（[ADR-0025](../../12_ADR/0025-規約の本文と版はリポジトリのMarkdownで管理.md)）。同意に使う現在の版は API01 で取得する

画面表示制御:

- 未ログインのヘッダーを使う
- PC では左に目次、右に本文を置く。スマホでは本文を 1 列に置く
- 制定日・施行日を表示する
- 本文の正本は、life リポジトリにある規約の原稿（`legal/terms.md`）。公開する前に、運営者名・問い合わせ先などの空欄を埋める
- 有料契約は [UIS38](../UIS38/README.md#展示プラスの契約条件)、退会は [UIS35](../UIS35/README.md#退会の期間と公開停止) と条件を揃える。原稿への反映が済んでいない部分を、未決の製品仕様として扱わない

### 補足

再同意（[UIS08](../UIS08/README.md)）で使う「現在の版」と、このページに表示する版は一致させる。
