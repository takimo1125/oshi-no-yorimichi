## 概要

機能目的:

- 有料プラン（展示プラス）の販売に必要な、特定商取引法に基づく表記を公開する

機能概要:

- 販売事業者・料金・支払い方法・解約などの表記
- 展示プラスの案内への導線

関連する機能：H-05、G-01

### 1. 初期表示

起動パラメータ：なし

利用API：なし

画面表示制御:

- 未ログインのヘッダーを使う
- PC では項目と内容を 2 列に置く。スマホでは項目の下に内容を置く
- 本文の正本は、life リポジトリにある原稿（`legal/commerce.md`）。公開する前に、販売事業者・所在地・税込の表示・支払いの時期・解約・返金などの空欄を埋める
- 料金・契約期間・支払方法・解約・通常返金の条件は [UIS38](../UIS38/README.md#展示プラスの契約条件) と一致させる。決定済みの条件が原稿に未反映であることと、販売事業者等の未確定欄を区別する

### 2. 展示プラスの案内へ

[UIS38](../UIS38/README.md) へ遷移する。未ログインの場合は [UIS05](../UIS05/README.md) を経由する。
