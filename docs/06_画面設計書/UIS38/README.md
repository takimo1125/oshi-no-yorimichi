## 概要

機能目的:

- 展示プラス（月額 300 円）の内容と、本人の契約の状態を見てもらい、申し込み・契約の管理へ進んでもらう

機能概要:

- 契約の状態に合わせた表示（未加入・契約中・支払い情報の確認が必要・契約終了）
- 申し込み・契約の管理・PDF の書き出しへの導線

関連する機能：G-01、G-02、E-06、E-07

### 展示プラスの契約条件

| 項目 | 条件 |
| --- | --- |
| 料金 | 月額 300 円（税込の支払総額） |
| 初回の支払い | 申し込み時に初回分を決済する。支払いの確認後に有料機能を開始する |
| 支払方法 | 初版は Stripe Checkout によるカード決済 |
| 契約期間と更新 | 加入日を基準とする 1 か月単位の自動更新。固定の 30 日間とはしない。次回請求日時は Stripe の契約情報を使用する |
| 通常の解約 | 次回の自動更新を停止し、支払い済み期間の終了までは有料機能を利用できる |
| 通常解約の返金 | 自己都合の途中解約では日割り返金しない |
| 誤請求などの返金 | 問い合わせを受けて、運営が一件ずつ判断し、Stripe のダッシュボードから返金する。返金を申し込む画面は作らない |
| 解約予約の取消し | 支払い済み期間の終了前なら、契約管理（カスタマーポータル）から解約の予約を取り消し、自動更新を続けられる。取り消しても支払い済み期間と次回請求日時は変えない。期間の終了後は取り消せず、再申し込み（`billing_rejoin`）で始め直す |
| 退会したとき | 退会の受付時に次回の自動更新を停止する。返金は通常の解約と同じく日割りしない。退会を取り消しても自動更新は自動で再開しない（[UIS35](../UIS35/README.md#退会の期間と公開停止)） |
| 更新の支払い失敗 | 無料の猶予期間は設けず、支払い済み期間の終了後は有料機能を停止する。支払い回復をサーバーで確認してから再開する |
| 支払いの再試行 | 更新の支払いに失敗したら、Stripe の既定（2 週間以内に最大 8 回）で再試行する。すべて失敗したら契約を終了する。終了後は再申し込み（`billing_rejoin`）で始め直す |
| 月末の加入 | 更新日は Stripe の請求サイクルに従う。画面には Stripe の次回請求日時を表示する。実際の更新日は実装前に Stripe で確かめる |
| 展示数と保存容量 | 有料時の展示数に上限を設けない。保存容量の上限は無料・有料とも設けない（[UIS25](../UIS25/README.md#展示数と契約終了後の操作)） |
| 契約終了後のデータ | 閲覧を維持する。展示の保持数と編集・削除は [UIS25](../UIS25/README.md#展示数と契約終了後の操作) に従う |

有料機能の開始・再開は、決済通知と決済用キューの処理結果に基づいて判定する。申し込みやポータルからブラウザーが戻ったことだけでは開始・再開しない。利用権終了後も、受理済みで失敗した PDF の再依頼は [共通仕様](../README.md#書き出しの失敗と再依頼) に従う。

料金は「月額300円（税込）」と表示する。契約中の画面（`plus_active`）には、Stripe の契約情報の次回請求日時を「次回のお支払い日」として表示する。Figma の日付は例で、仮の日付を実際の表示に使わない。法務本文への反映は別に行う。

### 1. 初期表示

起動パラメータ：なし

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API75 | 本人の展示プラスの契約の状態と有料権限を取得する | なし |

画面表示制御：サーバーが持つ契約の状態で、次のように表示を変える。Stripe から戻ったことや、本人がボタンを押したことだけでは、契約中とみなさない

| 契約の状態 | 表示 | 画面モデル |
| --- | --- | --- |
| 未加入 | できること・料金（無料 0 円・展示プラス月額 300 円）・「展示プラスをはじめる」 | `plus_inactive` |
| 契約中 | 「契約中」・できること・解約後も作成済みの記録と展示は見られること・「契約を管理する」 | `plus_active` |
| 支払い情報の確認が必要 | 支払い情報の確認を求める案内・「お支払い情報を確認する」 | `billing_payment_attention` |
| 契約終了 | 作成済みの日記と展示は引き続き見られること・わたしの記録とわたしの展示への導線・「展示プラスをもう一度はじめる」 | `billing_canceled` |
| 申し込みの確認中 | この画面は表示せず、[UIS40](../UIS40/README.md) へ遷移する | |
| 解約の反映の確認中 | この画面は表示せず、[UIS42](../UIS42/README.md) へ遷移する | |

- 契約終了の状態で「展示プラスをもう一度はじめる」を押したら、同じ画面で再申し込みの案内（`billing_rejoin`）を表示し、「お申し込み内容を確認する」で [UIS39](../UIS39/README.md) へ遷移する。以前のカードや契約が自動で戻るとは表示しない

### 2. 展示プラスをはじめる

[UIS39](../UIS39/README.md) へ遷移する。

### 3. 契約を管理する・お支払い情報を確認する

[UIS41](../UIS41/README.md) へ遷移する。支払い情報の確認が必要な場合も、新しい申し込み（Stripe Checkout）へは進ませない。

### 4. PDFを書き出す

まず [UIS25](../UIS25/README.md) で対象の展示を選んでもらい、その展示の [UIS28](../UIS28/README.md) から [UIM07](../UIM07/README.md) を開く。展示を選ばずに確認モーダルは開かない。有料権限の確認は [UIM07](../UIM07/README.md) の条件に従う。

Figma のリンクは [UIS25](../UIS25/README.md)（`exhibitions`）を示す。UIS25 に、展示を選ぶための特別な表示は置かない。
