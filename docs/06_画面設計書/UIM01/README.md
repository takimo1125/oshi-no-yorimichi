## 概要

機能目的:

- 登録や再同意の画面を離れずに、利用規約・プライバシーポリシーの全文を読んでもらう

機能概要:

- 利用規約またはプライバシーポリシーの全文の表示（スクロールできる）
- 全文のページへの導線

関連する機能：H-05

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 指定された文書の全文を表示する |
| 2 | 閉じる・× | ボタン押下 | モーダルを閉じ、呼び出し元へ戻る |
| 3 | 全文を別ページで読む | リンク押下 | [UIS46](../UIS46/README.md) または [UIS47](../UIS47/README.md) へ遷移（NAVIGATE） |

## イベント詳細

### Figma の操作と遷移

共通ナビゲーションは [画面共通の動き](../README.md#全画面で共通の動き) を参照。表はリンクが設定された操作を示す。リンクのない操作の処理・未確定事項は後述する。

| 画面モデル | 操作 | 遷移先・状態 | 表示方法 |
| --- | --- | --- | --- |
| `terms_modal`・`reconsent_terms_modal` | 全文を別ページで読む | [UIS46](../UIS46/README.md)（`terms`） | 画面へ遷移 |
| `privacy_modal`・`reconsent_privacy_modal` | 全文を別ページで読む | [UIS47](../UIS47/README.md)（`privacy`） | 画面へ遷移 |

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| document | `terms` または `privacy` | 表示する文書 |
| caller | `UIS02`・`UIS03`・`UIS04`・`UIS08` のどれか | 閉じたときの戻り先 |

利用API：なし（[UIS46](../UIS46/README.md) と同じ）

画面表示制御:

- PC では画面の中央のダイアログ、スマホでは背の高いシートで表示する
- 背景には呼び出し元の画面をそのまま残す
- 登録の画面から開いたもの（`terms_modal`・`privacy_modal`）と、再同意の画面から開いたもの（`reconsent_terms_modal`・`reconsent_privacy_modal`）は、背景が違うだけで中身は同じ

### 2. 閉じる・×

呼び出し元へ戻る。呼び出し元の入力の内容と同意欄の状態は変えない。開いて閉じただけでは同意しない。

### 3. 全文を別ページで読む

Figma の NAVIGATE のリンクに従い、全文のページへ遷移する。全文を開いただけでは同意済みにしない。元のフォームへの戻り方と、入力内容・同意欄の保持方法は未確定。再同意を必要とする保護された操作は引き続き認可で確認する。
