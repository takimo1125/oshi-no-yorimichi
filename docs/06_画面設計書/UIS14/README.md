## 概要

機能目的:

- 1 件の記録を詳しく見てもらい、いいね・コメントで反応してもらう

機能概要:

- 写真（複数枚をめくる）・投稿者・ひとこと・記録の種類・タグ・グッズの表示
- いいね・コメント
- ストーリーズ用画像の書き出し・通報への導線
- 本人の記録の場合は、編集・削除への導線

関連する機能：C-01、D-01、D-04、E-04、H-01

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| post_id | 表示する記録の ID | |
| saved | `true` | [UIS12](../UIS12/README.md) で保存した直後だけ渡す |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API30 | 記録を取得する | post_id |
| API33 | 記録へのコメントを取得する | post_id |

画面表示制御:

- 他の利用者の公開された記録（`post_detail`）
  - いいね・コメント・通報を表示する
  - 「ストーリーズにする」は表示しない。他人の写真を加工して外部の SNS に載せられないようにするため
  - 編集・削除は表示しない
- 本人の公開した記録（`own_post_detail_public`）
  - 「公開」の印を付ける
  - 編集・削除・コメント・ストーリーズにするを表示する
  - 通報は表示しない
- 本人の非公開の記録（`own_post_detail`）
  - 「自分だけ」の印を付ける
  - 編集・削除・ストーリーズにするを表示する。いいね・コメント・通報は表示しない
  - 書き出した画像は本人の手元に保存するもので、記録の公開範囲は変えない
- 写真のない記録（`post_detail_text`・`own_post_detail_text`）は、写真の枠や写真をめくる操作を表示しない
- [UIS12](../UIS12/README.md) での更新成功後に `saved=true` が渡された場合は、写真・文字、公開・非公開のどの組み合わせでも「変更を保存しました」を表示する
- 公開範囲と写真の有無は、取得した保存済み記録の値で判断する。`saved` は保存完了の表示だけを切り替え、公開範囲・写真の有無・利用できる操作は変更しない
- `own_post_detail_updated` は非公開の写真記録の保存完了例。公開記録・文字記録の保存完了と、本人の公開文字記録の専用フレームは Figma に未反映。既存の表示例を使う場合も保存済み記録の公開範囲を維持する
- 他の利用者の非公開の記録・存在しない記録の場合は、[UIS49](../UIS49/README.md) を表示する
- PC では写真を左、記録の情報を右に置き、その下にコメントを置く

### 3. いいね

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API35・API36 | いいねする、またはいいねを取り消す | post_id |

画面表示制御:

- 同じ画面でいいねの状態を切り替える
- いいねの数は控えめに表示する。表示するかどうかを含めて未確定
- いいねされた相手への通知は、サーバー側で通知用キューを通して作る（F-02）

### 4. コメントする

入力チェック:

| 項目 | チェック |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |

画面表示制御:

- 投稿に成功したら、コメントの一覧を取得し直す
- 記録の投稿者への通知は、サーバー側で通知用キューを通して作る（F-02）

コメントは、各コメントのメニューから同じ流れで通報する（`target_type` は `comment`）。各コメントの「…」を押すと、「このコメントを通報する」だけのメニューを開く（`post_detail_comment_menu`）。
