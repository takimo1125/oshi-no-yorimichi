## 概要

機能目的:

- 登録済みの利用者にログインしてもらう

機能概要:

- メールアドレスとパスワードでのログイン
- Google 連携でのログイン
- 新規登録・パスワード再設定への導線

関連する機能：A-01

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| return_to | ログイン後に開く画面 | ログインが必要な画面から移動してきた場合だけ渡す |

利用API：なし

### 2. ログイン

入力チェック:

| 項目 | チェック |
| --- | --- |
| メールアドレス | 必須 |
| パスワード | 必須 |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API05 | メールアドレスとパスワードで認証する | 入力フォームの値 |
| API13 | 利用規約・プライバシーポリシーの現在の版と、本人が同意した版を文書ごとに照合する | 認証した利用者 |

画面表示制御:

- 認証に失敗した場合は、エラーを表示する。文言は未確定
- 未ログインで、いいね・コメント・フォローなどログインが必要な操作をしたときは、操作を実行せずにこの画面を開き、「続けるには、ログインしてください。ログインした後は、開いていた画面に戻ります。」を表示する（`login_required`）。ログインした後は `return_to` の画面へ戻る
- 認証に成功し、退会を受け付けた後で削除対象になる前の利用者の場合は、同意の確認より先に、[UIS52](../UIS52/README.md) へ遷移する
- 削除対象になった利用者のログインは、通常の認証失敗と同じ表示にする。退会したかどうかを明かさない
- 運営が停止した利用者のログインは `403 account_suspended` になる。表示は未確定
- 認証に成功し、同意していない版の文書がある場合は、[UIS08](../UIS08/README.md) へ遷移する
- 認証に成功し、両方の文書に同意済みの場合は、`return_to` の画面へ遷移する。`return_to` がない場合は [UIS09](../UIS09/README.md) へ遷移する

### 3. Googleでログイン

Google の認証画面へ移動する。認証に成功して戻ったら、次の共通分岐に従う。

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API06 | Google の認証を始める | `mode=login`、return_to |

画面表示制御:

- Google の認証を中断した・失敗した場合は、`google_error=1` を付けてこの画面に戻る。表示は未確定
- Google が確認済みとしていないメールアドレスで、メールで登録済みの利用者がいる場合は、`google_not_linked=1` を付けてこの画面に戻り、「Google でログインできませんでした」の案内を表示する（`login_google_not_linked`。共通分岐の 4 行目）

### Google 認証後の共通分岐

[UIS02](../UIS02/README.md)・[UIS04](../UIS04/README.md) の登録の入口と、この画面のログインの入口で同じ判定を使う。

| 利用者の状態 | 動き |
| --- | --- |
| サービスに一度も登録していない | [UIS03](../UIS03/README.md) でユーザー名と同意などの登録情報を入力し、登録を完了する |
| サービスへの登録と、その Google アカウントの連携が済んでいる | 登録情報の入力を繰り返さず、イベント 2 と同じ退会中の確認・同意確認・元の画面への復帰に進む |
| メールで登録済み（確認コードの入力済み）で、その Google アカウントは未連携。Google がメールアドレスを確認済みとしている | 止めずに自動で同じ利用者に結び付け、2 行目と同じ流れでログインする。結び付けたことを本人にメールで知らせる（[ADR-0026](../../12_ADR/0026-確認済みのメールアドレスが一致したら認証方式を自動で結び付ける.md)） |
| メールで登録済み（確認コードの入力済み）で、その Google アカウントは未連携。Google がメールアドレスを確認済みとしていない | ログインも登録もしない。「メールアドレスでログインしてから、設定で Google を追加してください」と案内する（追加は [UIS31](../UIS54/README.md#2-google-を追加する)）。案内は `login_google_not_linked` |
| 同じメールアドレスの利用者が、確認コードの入力を済ませていない | 扱いは未確定 |

認証方式の連携方針は [ADR-0026](../../12_ADR/0026-確認済みのメールアドレスが一致したら認証方式を自動で結び付ける.md) を参照。Figma のログインボタンのホームへのリンクは、登録・連携済みで同意も済んでいる通常の例を示す。

### ログイン後の分岐

Figma のログインボタンのリンクはホーム（`home`）を示す。「02 主要な動線」では規約への同意済みかでホームと再同意に分岐する。認証後の同意確認はイベント 2 に従い、リンクだけで再同意を省略しない。
