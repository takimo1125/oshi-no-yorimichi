## 概要

機能目的:

- タグ名やユーザー名から、見たいタグ・利用者を見つけてもらう

機能概要:

- タグ名での検索
- ユーザー名での検索
- 本文の検索は行わない

関連する機能：C-05

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | タグの検索を表示する |
| 2 | タグ・ユーザー | タブ押下 | 同じ画面で検索の対象を切り替える |
| 3 | 検索語の入力・さがす | 入力・ボタン押下 | タグは入力に合わせて候補を表示する。ユーザーは「さがす」を押したときに検索する |
| 4 | 検索結果のタグ | 項目押下 | [UIS22](../UIS22/README.md) へ遷移。`pick=tag` のときは `return_to` の画面へ戻る |
| 5 | 検索結果のユーザー | 項目押下 | [UIS23](../UIS23/README.md) へ遷移 |
| 6 | 検索し直す | ボタン押下 | 同じ検索対象の通常表示に戻す（0 件の状態から） |

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| type | `tags` または `users` | 省略したら `tags` |
| q | 検索する語 | 省略したら未入力 |
| pick | `tag` | タグを選ぶために開いたとき。[UIS11](../UIS11/README.md#4-タグを追加)・[UIS12](../UIS12/README.md) から渡す |
| return_to | 元の画面 | `pick=tag` のとき。タグを押したら [UIS22](../UIS22/README.md) ではなく、`picked_tag=<タグ名>` を付けてこの画面へ戻る |

利用API：`q` が渡された場合は、イベント 3 と同じ

ユーザー検索と検索結果から開く他の利用者のプロフィール詳細は、[未ログインの閲覧の共通仕様](../README.md#未ログインの閲覧) に従い、未ログインでも利用できる。

### 2. タグ・ユーザー

同じ画面で検索の対象を切り替える。入力済みの語は保ち、切り替えた対象で検索し直す。

### 3. 検索語の入力・さがす

入力チェック:

| 項目 | チェック |
| --- | --- |
| 検索する語 | 必須 |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API50 | タグ名で検索する | q |
| API51 | ユーザー名で検索する | q |

画面表示制御:

- タグの検索では、入力に合わせて候補を表示する。1 文字目から、入力が 0.3 秒止まったときに候補を出す。Figma のタグの検索には「さがす」ボタンがない
- ユーザーの検索では、「さがす」を押したときに検索する
- タグの検索では、タグ名と説明を表示する
- ユーザーの検索では、アイコン・表示名・自己紹介を表示する。連絡先・非公開の記録・活動の状況は出さない
- 結果が 0 件の場合は、0 件の表示と、検索し直す導線を表示する（`search_tags_empty`・`search_users_empty`）
- タグもユーザー名も、検索語を含むものがすべて当たる部分一致で検索する。英字の大文字と小文字、全角と半角の違いは区別しない
