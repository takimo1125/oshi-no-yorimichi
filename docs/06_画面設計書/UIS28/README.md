## 概要

機能目的:

- 選んだ記録の並び順と、展示用の解説を決めてもらい、展示を保存・公開してもらう

機能概要:

- 展示のタイトル・表紙の変更
- 記録の並び順の変更（ドラッグ）と、記録ごとの展示用の解説
- 公開範囲の選択と保存
- プレビュー・ストーリーズ用画像の書き出し・PDF の書き出しへの導線

関連する機能：E-01、E-02、E-03、E-04、E-06

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| exhibition_id | 作成中・編集中の展示の ID | 新規でも渡す（画面が決めた保存前の ID）。新規作成中の基本情報と選んだ記録は、この ID をキーにして sessionStorage から読む（[API 設計書の「画面間の入力の受け渡し」](../../07_API設計書/README.md#画面間の入力の受け渡し)） |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API64 | 展示を取得する | exhibition_id |

画面表示制御:

- 本人の展示でない場合は編集させない
- 新規作成中は、引き継いだ基本情報と選んだ記録を表示する。初回保存前は保存済み展示の `exhibition_id` を前提にせず、展示取得 API は保存済み展示の ID がある場合だけ呼ぶ
- 展示用の解説は、元の記録のひとこととは別に持つ。ここで解説を変えても、元の記録は変わらない
- 公開範囲には、保存済みの値を選んだ状態で表示する。新しく作るときは、[UIS26](../UIS26/README.md) で選んだ値を表示する

### 3. 保存する

入力チェック:

| 項目 | チェック |
| --- | --- |
| 展示のタイトル | 必須 |
| 記録 | 1 件以上 |
| 展示用の解説 | 任意。1 件の記録につき 200 文字まで |
| 公開範囲 | 公開・非公開のどちらかを選んでいること |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API65 | 展示を作成する、または更新する | exhibition_id（既存の展示のとき）、タイトル、表紙、記録の順序と解説、公開範囲 |

画面表示制御:

- 保存に成功したら、同じ画面に保存したことを表示する
- 新規展示はこの操作で初めて保存し、保存した展示の ID を以後の編集で使用する。既存展示の場合は、その展示を更新する
- 保存結果を確認できない場合は [共通仕様](../README.md#保存の結果を確認できないとき) に従い、この画面に入力を保持する
- 非公開から公開に変えた場合、フォロワーへの通知は、サーバー側で通知用キューを通して作る（E-03）。通知するのは、その展示を初めて公開したときの 1 回だけ。公開・非公開を切り替え直しても、もう一度は通知しない

### 4. プレビューで確認

Figma のリンクは [UIS29](../UIS29/README.md)（`exhibition_preview`）を示す。保存前でも、入力中の基本情報・選んだ記録・順序・解説・公開範囲を使ってプレビューできる。プレビューを開くために保存・公開は行わない。入力内容を保持し、編集手順へ戻って続きを編集できる。

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| exhibition_id | 作成中・編集中の展示の ID | 新規でも渡す（保存前の ID） |
| preview | `true` | 所有者のプレビュー。入力中の内容は sessionStorage から読む（[API 設計書の「画面間の入力の受け渡し」](../../07_API設計書/README.md#画面間の入力の受け渡し)） |

### 6. Instagram用の画像を書き出す

書き出しには保存済みの展示を使う。初回保存前や未保存の変更がある場合は、先にこの画面の「保存する」で保存してから書き出すよう案内する。書き出し操作による自動保存はしない。保存済みの内容を確認したら [UIS43](../UIS43/README.md) へ遷移する。

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| target_type | `exhibition` | |
| target_id | exhibition_id | |

### 7. PDFを書き出す

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API75 | 本人の有料権限を取得する | なし |

画面表示制御:

- 初回保存前や未保存の変更がある場合は、先にこの画面の「保存する」で保存してから書き出すよう案内する。書き出し操作による自動保存はしない
- 有料権限が有効なら、[UIM07](../UIM07/README.md) を起動する
- 有料権限がなければ、[UIM08](../UIM08/README.md) を起動する（`feature` は `pdf_export`）
- 申し込みの確認中なら、[UIS40](../UIS40/README.md) へ遷移する

起動パラメータ（[UIM07](../UIM07/README.md) へ渡す）:

| Name | Value | Memo |
| --- | --- | --- |
| exhibition_id | 編集中の展示の ID | |
