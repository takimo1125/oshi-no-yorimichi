## 概要

機能目的:

- 利用規約・プライバシーポリシーが更新された後、ログインした利用者に更新後の版への同意をもらう

機能概要:

- 更新された文書だけを表示し、文書ごとに同意をもらう
- 本文の表示
- 同意しない場合のログアウト

関連する機能：H-05

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 同意していない版の文書だけを表示する |
| 2 | 同意欄 | チェック | 対象の文書すべてを選択したら「同意して続ける」を有効にする |
| 3 | 全文を読む | リンク押下 | [UIM01](../UIM01/README.md) を起動 |
| 4 | 同意して続ける | ボタン押下 | 同意を記録し、もともと開こうとした画面へ遷移 |
| 5 | ログアウト | リンク押下 | ログアウトし、[UIS05](../UIS05/README.md) へ遷移 |

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| return_to | もともと開こうとした画面 | |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API13 | 利用規約・プライバシーポリシーの現在の版と、本人が同意した版を文書ごとに照合する | ログイン中の利用者 |

画面表示制御:

- 両方の文書が更新されている場合は、2 つの同意欄を表示する（`legal_reconsent`）
- 片方の文書だけが更新されている場合は、その文書の同意欄だけを表示する（`legal_reconsent_terms_only`・`legal_reconsent_privacy_only`）
- 両方に同意済みの場合は、この画面を表示せず `return_to` の画面へ遷移する
- 同意欄は未選択で始め、「同意して続ける」は無効にする
- ヘッダーにはロゴとログアウトだけを置く

### 2. 同意欄

画面表示制御:

- 表示している同意欄をすべて選択したら、「同意して続ける」を有効にする（`legal_reconsent_ready`・`legal_reconsent_terms_only_ready`・`legal_reconsent_privacy_only_ready`）
- 1 つでも未選択の欄がある間は、無効のままにする（`legal_reconsent_terms_checked`・`legal_reconsent_privacy_checked`）
- 選択しただけでは同意を記録しない

### 3. 全文を読む

[UIM01](../UIM01/README.md) を起動する。同意欄の状態は保ったまま開く。開いたり閉じたりしただけでは同意しない。

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| document | `terms` または `privacy` | 表示する文書 |
| caller | `UIS08` | 閉じたときの戻り先 |

### 4. 同意して続ける

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API14 | 同意を記録する | 文書の識別子、同意した版 |

記録する内容は、利用者・文書の識別子・同意した版・同意した日時とする。同意したかどうかの真偽値 1 つだけでは管理しない。

画面表示制御:

- 記録に成功したら `return_to` の画面へ遷移する。`return_to` がない場合は [UIS09](../UIS09/README.md) へ遷移する
- 画面を表示した後に文書がさらに更新されていた場合は、古い版への同意として扱わず、最新の内容を表示し直す

### 5. ログアウト

同意せずに利用をやめる出口。ログアウトして [UIS05](../UIS05/README.md) へ遷移する。

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API10 | ログアウトする | なし |

### 補足

ほかの画面の URL を直接開いて再同意を飛ばせないよう、画面の遷移と API の認可の両方で同意の状態を確かめる。
