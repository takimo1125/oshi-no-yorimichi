## 概要

機能目的:

- ある利用者のプロフィールと、公開している記録・展示を見てもらう

機能概要:

- プロフィール（アイコン・表示名・自己紹介・推しのタグ）の表示
- 公開している記録と展示の表示（タブで切り替え）
- 他の利用者の場合は、フォロー・ブロック・ミュート・通報
- 本人の場合は、プロフィールの編集・記録と展示の管理への導線

関連する機能：A-02、C-04、D-02、D-03、H-01

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| user_name | 表示する利用者のユーザー名 | ヘッダーの「プロフィール」から開いたときは本人 |
| tab | `posts` または `exhibitions` | 省略したら `posts` |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API52 | 利用者のプロフィールと、本人がフォローしているかを取得する | user_name |
| API53 | 利用者の公開された記録を取得する | user_name、ページ送りの位置 |

画面表示制御:

- 他の利用者のページ（`user_posts`）
  - 「フォローする」と「その他」を表示する
  - フォローしている場合は、フォロー済みの表示にする（`user_following`）
  - 公開している記録だけを表示する。非公開の記録のタイトル・サムネイル・空の枠・件数は出さない
- 本人のページ（`profile_self`）
  - 「プロフィールを編集」と「わたしの記録を見る」を表示する
  - フォロー・その他・通報は表示しない
  - 公開している記録だけを表示する。非公開の記録は [UIS15](../UIS15/README.md) で見る
- 記録が 0 件の場合は、0 件の表示にする（`user_posts_empty`）
- フォロワー数・フォロー数の数字は表示しない（数字は控えめにする方針）
- ブロックされている利用者のページを開いた場合は、[UIS49](../UIS49/README.md) と同じく存在しないものとして表示する
- ブロックしている利用者のページを開いた場合は、記録・展示・プロフィールの内容を表示せず、ブロック中であることと解除の操作だけを表示する（`user_blocked`）。解除したら、フォローしていない状態のページ（`user_posts`）にする
- ミュートしている利用者のページは、そのまま表示する。メニューの「ミュートする」の代わりに「ミュートを解除する」を表示する（`user_posts_muted`）

### 2. 投稿・展示

展示のタブを選んだ場合:

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API54 | 利用者の公開された展示を取得する | user_name |

画面表示制御:

- 他の利用者の場合は、公開している展示だけを表示する（`user_exhibitions`・`user_exhibitions_following`）。作成・編集の操作は出さない
- 本人の場合は、公開している展示を表示し、「わたしの展示を管理」を表示する（`profile_self_exhibitions`）
- 展示が 0 件の場合は、0 件の表示にする（`user_exhibitions_empty`）

### フォロー済みのタブ切り替え

フォローしている人のページでタブを切り替えても、フォロー済みの表示のまま（`user_following`・`user_exhibitions_following`）にする。タブの切り替えだけでフォロー解除 API は呼ばない。
