## 概要

機能目的:

- 1 つのタグが付いた公開記録を眺めてもらい、好きなタグをフォローしてもらう

機能概要:

- タグが付いた公開された記録を新しい順に表示する
- タグのフォロー。フォローを解除する操作は未確定

関連する機能：C-02、C-03、F-03

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | タグと、タグが付いた公開された記録を表示する |
| 2 | フォローする・フォロー中 | ボタン押下 | 同じ画面でタグのフォローの状態を切り替える |
| 3 | 記録の写真・ひとこと | 項目押下 | [UIS14](../UIS14/README.md) へ遷移 |
| 4 | 投稿者 | 項目押下 | [UIS23](../UIS23/README.md) へ遷移 |
| 5 | みんなのよりみちを見る | ボタン押下 | 0 件の状態から [UIS09](../UIS09/README.md) へ遷移 |

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| tag_name | 表示するタグの名前 | |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API46 | タグの情報と、本人がフォローしているかを取得する | tag_name |
| API47 | タグが付いた公開された記録を新しい順に取得する | tag_name、ページ送りの位置 |

画面表示制御:

- 「好きなタグの新着は金曜の週末便で。」を表示する
- フォローしている場合は「フォロー中」、していない場合は「フォローする」を表示する（`tag_following`・`tag`）
- 記録が 0 件の場合は、0 件の表示にする（`tag_empty`）

### 2. フォローする・フォロー中

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API48・API49 | タグをフォローする、またはフォローを解除する | tag_name |

画面表示制御:

- 同じ画面でボタンの表示を切り替える
- 「フォローする」のリンクは `tag_following` を示す。「フォロー中」のリンクは設定されておらず、解除の操作・解除前の確認は未確定。上の解除 API はその条件が決まった場合の候補

### 補足

フォローしたタグの新着は、毎週金曜 19:00（日本時間）にアプリ内の通知とメールでまとめて届ける（F-03）。
