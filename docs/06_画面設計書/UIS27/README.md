## 概要

機能目的:

- 月をまたいで、展示に入れたい自分の記録を選んでもらう

機能概要:

- 本人の記録を月ごとに表示する
- 記録の選択と選択の解除（月を切り替えても選択を保つ）
- 選んだ記録の一覧

関連する機能：E-01

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 本人の記録を月ごとに表示する |
| 2 | 前の月・次の月 | ボタン押下 | 選択を保ったまま、別の月の記録を表示する |
| 3 | 記録 | 項目押下 | 記録を選ぶ、または選択を解除する |
| 4 | 選んだ記録で並べる | ボタン押下 | [UIS28](../UIS28/README.md) へ遷移 |
| 5 | 基本情報に戻る | ボタン押下 | [UIS26](../UIS26/README.md) へ遷移 |

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| exhibition_id | 作成中・編集中の展示の ID | 新規でも渡す（画面が決めた保存前の ID）。基本情報と選んだ記録は、この ID をキーにして sessionStorage から読む（[API 設計書の「画面間の入力の受け渡し」](../../07_API設計書/README.md#画面間の入力の受け渡し)） |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API32 | 本人の記録を月ごとに取得する | 月 |
| API64 | 展示に入っている記録を取得する | exhibition_id（渡されたときだけ） |

画面表示制御:

- 記録ごとに、日付・記録の種類・選択中かどうかを表示する
- 選んだ記録の件数と一覧を表示する
- 非公開の記録も展示に入れられる。他の利用者には非公開の記録を表示しない。件数の上限は未確定

### 4. 選んだ記録で並べる

入力チェック:

| 項目 | チェック |
| --- | --- |
| 選んだ記録 | 1〜30 件 |

画面表示制御:

- 基本情報と選んだ記録を保ったまま、[UIS28](../UIS28/README.md) へ遷移する
- 新規展示はここでも保存・公開しない。初回保存は [UIS28 の「保存する」](../UIS28/README.md#3-保存する) で行う
