## 概要

機能目的:

- 本人がブロック・ミュートした人を確かめ、解除できるようにする

機能概要:

- ブロックした人とミュートした人の一覧
- ブロック・ミュートの解除

関連する機能：D-03

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | ブロックした人とミュートした人を表示する |
| 2 | ブロックを解除する・ミュートを解除する | ボタン押下 | 同じ画面で解除し、一覧から外す |
| 3 | 設定へ戻る | ボタン押下 | [UIS31](../UIS31/README.md) へ遷移 |

### 1. 初期表示

起動パラメータ：なし

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API61 | 本人がブロック・ミュートした利用者を取得する | なし |

画面表示制御:

- 「ブロックした人」と「ミュートした人」に分けて表示する
- ブロックした人はプロフィールの内容が見えないため、この一覧からも解除できるようにする。効果は [UIM05](../UIM05/README.md#ブロックの効果)・[UIM06](../UIM06/README.md#ミュートの効果) を参照
- いない場合は、それぞれ「ブロックしている人はいません」「ミュートしている人はいません」と表示する

### 2. ブロックを解除する・ミュートを解除する

確認を出さずに、同じ画面で解除する。

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API58・API60 | ブロック・ミュートを解除する | user_name、解除する種類 |

画面表示制御:

- 解除したら、その人を一覧から外す
- ブロックを解除しても、フォローは元に戻さない
