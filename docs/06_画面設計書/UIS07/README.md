## 概要

機能目的:

- メールに届いた確認コードを入力してもらい、新しいパスワードを決めてもらう

機能概要:

- 確認コードと新しいパスワードの入力
- パスワードの更新
- 確認コードの再送

関連する機能：A-01

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 確認コードを送ったことと、入力欄を表示する |
| 2 | パスワードを更新する | ボタン押下 | 確認コードを確かめてパスワードを更新し、[UIS05](../UIS05/README.md) へ遷移 |
| 3 | ログインにもどる | リンク押下 | [UIS05](../UIS05/README.md) へ遷移 |
| 4 | 確認コードを送り直す | ボタン押下 | 同じメールアドレスに確認コードを送り直す |

## イベント詳細

### Figma の操作と遷移

共通ナビゲーションは [画面共通の動き](../README.md#全画面で共通の動き) を参照。表はリンクが設定された操作を示す。リンクのない操作の処理・未確定事項は後述する。

| 画面モデル | 操作 | 遷移先・状態 | 表示方法 |
| --- | --- | --- | --- |
| 全状態 | パスワードを更新する | [UIS05](../UIS05/README.md)（`login`） | 画面へ遷移 |
| 全状態 | ログインにもどる | [UIS05](../UIS05/README.md)（`login`） | 画面へ遷移 |

### 1. 初期表示

メールのリンクから開く画面ではない。[UIS06](../UIS06/README.md) で確認コードの送信を依頼した後に表示する。

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| email | [UIS06](../UIS06/README.md) で入力したメールアドレス | 画面の間で引き継ぎ、URL には載せない |

利用API：なし

画面表示制御:

- 登録済みのメールアドレスであれば確認コードを送ったことと、メールに届いた確認コードと新しいパスワードを入力することを示す。登録済みかどうかで表示を変えない
- メールアドレスを引き継げない場合（この画面を直接開いた場合など）は、[UIS06](../UIS06/README.md) へ遷移する

### 2. パスワードを更新する

入力チェック:

| 項目 | チェック |
| --- | --- |
| 確認コード | 必須 |
| 新しいパスワード | 必須。8 文字以上で、英字と数字を両方含む（認証基盤 Cognito のパスワードの条件で設定する） |
| 新しいパスワード（確認用） | 必須。新しいパスワードと一致すること |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API12 | 確認コードを確かめ、パスワードを更新する（認証基盤 Cognito の確認コードを使う） | email、確認コード、新しいパスワード |

画面表示制御:

- 確認コードが違う・期限切れの場合は、確認コードの欄にエラーを表示する。登録されていないメールアドレスの場合も同じ表示にする
- 新しいパスワードが条件を満たさない場合は、新しいパスワードの欄にエラーを表示する
- 試行が多すぎる場合は、しばらく待ってから試すよう表示する
- 更新に成功したら、本人のすべてのセッションを失効させ、[UIS05](../UIS05/README.md) へ遷移する。自動でログインするかは未確定

### 4. 確認コードを送り直す

[UIS06](../UIS06/README.md) のイベント 2 と同じ処理で、引き継いだメールアドレスに確認コードを送り直す。登録済みかどうかで表示を変えない。
