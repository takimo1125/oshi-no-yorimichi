## 概要

機能目的:

- 受け取る通知の種類と、メールを受け取るかを選んでもらう

機能概要:

- アプリ内の通知の種類ごとのオン・オフ
- 週末便メールの受信のオン・オフ

関連する機能：A-03

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 保存済みの受信設定を表示する |
| 2 | 保存する | ボタン押下 | 受信設定を保存し、[UIS31](../UIS31/README.md) へ遷移 |
| 3 | 変更をやめる | ボタン押下 | 保存せずに [UIS31](../UIS31/README.md) へ遷移 |

### 1. 初期表示

起動パラメータ：なし

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API21 | 本人の通知の受信設定を取得する | なし |

画面表示制御:

- アプリ内の通知は、次の種類ごとにオン・オフを表示する
  - ソーシャルの動き（フォローされた・いいねやコメントがあった）
  - 展示の公開（フォローしている人の展示が公開された）
  - 週末便（フォローしているタグの新着のまとめ）
  - お迎え記念日
  - 書き出しの完了
- メールの受信は、週末便メールだけを分けて表示する
- 運営からのお知らせの受信設定は、初版では表示しない（[ADR-0014](../../12_ADR/0014-管理画面を第2版へ移す.md)）
- 各項目の初期値は未確定。画面モデルのオン・オフは表示の例で、初期値ではない

### 2. 保存する

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API22 | 本人の通知の受信設定を更新する | 種類ごとのオン・オフ |

画面表示制御:

- 更新に成功したら [UIS31](../UIS31/README.md) へ遷移する
