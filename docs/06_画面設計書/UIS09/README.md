## 概要

機能目的:

- ほかのファンの公開された記録を眺めてもらう。サービスの一番の入口

機能概要:

- 公開された記録を日付ごとに新しい順で表示する（新着）
- フォローしている利用者と、フォローしているタグの公開された記録を表示する（フォロー中）
- 検索・週刊ギャラリー・記録の作成への導線

関連する機能：C-01、C-07、D-02

### 1. 初期表示

起動パラメータ：なし

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API37 | 公開された記録を新しい順に取得する | ページ送りの位置 |

画面表示制御:

- 記録を日付ごとにまとめて表示する
- 1 日の記録が 6 件以上ある場合は、先頭の 5 件だけを表示し、残りを「続きを読む（残り n 件）」に畳む（`home_day_collapsed`）。これは 1 日ごとの表示の区切りで、投稿数や一覧全体の上限ではない
- 記録が 0 件の場合は「まだ公開された記録がありません。」と、記録の作成への導線を表示する（`home_new_empty`）
- ブロック・ミュートした利用者の記録は表示しない
- 未ログインの公開一覧と、ログインを必要とする操作は [共通仕様](../README.md#未ログインの閲覧) に従う。ブロック・ミュートなど本人に依存する取得・絞り込みはログイン時に限る

### 2. 新着・フォロー中

同じ画面で一覧を切り替える。

「フォロー中」は本人の一覧のためログインを必要とする。未ログインでは個人のフォロー情報を取得せず、ログインへ案内する（`home_guest` の「フォロー中」から [UIS05](../UIS05/README.md) の `login_required` へ）。

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API38 | フォローしている利用者と、フォローしているタグの公開された記録を新しい順に取得する | ページ送りの位置 |

画面表示制御:

- 利用者とタグの両方から同じ記録が当たった場合は、1 件として表示する
- フォロー中の一覧に記録がない場合は、0 件の表示にする（`home_following_empty`）。フォローしている人が 0 人であることと、記録が 0 件であることを同じものとして扱わない

### 3. 続きを読む

同じ日の記録を、同じ順番のまま全件表示する（`home_day_expanded`）。

| Name | Value | Memo |
| --- | --- | --- |
| post_id | 押した記録の ID | |

[UIS23](../UIS23/README.md) へ遷移する。

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |

### 11. 閉じる

同じ画面でその日の残りの記録を畳む。表示する日付や記録の順序は変えない。
