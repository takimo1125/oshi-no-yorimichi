## 概要

機能目的:

- メールアドレスとパスワードで登録してもらう

機能概要:

- ユーザー名・メールアドレス・パスワードの入力
- 利用規約・プライバシーポリシーへの同意
- Google 連携での登録・ログインへの導線

関連する機能：A-01

### 1. 初期表示

起動パラメータ：なし

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API01 | 規約の現在の版を取得する | なし |

画面表示制御:

- 同意欄は未選択で始める

### 2. 登録する

入力チェック:

| 項目 | チェック |
| --- | --- |
| ユーザー名 | 必須。3〜20 文字。半角の英小文字・数字・アンダースコア（_）だけ。大文字と小文字を区別せずに、ほかの利用者と重複させない |
| メールアドレス | 必須。メールアドレスの形式であること |
| パスワード | 必須。8 文字以上で、英字と数字を両方含む（認証基盤 Cognito のパスワードの条件で設定する） |
| パスワード（確認用） | 必須。パスワードと一致すること |
| 同意欄 | 選択していること |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API02 | 利用者を登録し、最新の利用規約・プライバシーポリシーへの同意を記録する | ユーザー名、メールアドレス、パスワード、同意した文書の版 |

画面表示制御:

- 入力チェックに通らない場合は、登録しない。項目ごとに理由を表示する
- メールアドレスの確認は、届いた確認コードを入力する方式にする（認証基盤 Cognito の確認コード）
- メールアドレスがすでに登録済みでも、API02 は同じ応答を返す。画面は「確認コードを送りました」と表示し、登録済みの人には「すでに登録されています」というメールが届く。登録済みかどうかを画面から読み取れないようにする
- 確認コードの入力は API03、再送は API04 を使う
- メールアドレスの確認が完了するまで通常利用を開始しない。登録とメール確認の両方が成功したら [UIS09](../UIS09/README.md) へ遷移する
- 登録を受け付けたら、同じ画面で確認コードの入力の表示（`signup_email_confirm`）にする。確認前にホームへ進めない

### 5. 利用規約・プライバシーポリシー

[UIM01](../UIM01/README.md) を起動する。入力中の内容は保ったまま開く。閉じても同意欄は選択しない。

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| document | `terms` または `privacy` | 表示する文書 |
| caller | `UIS04` | 閉じたときの戻り先 |

### 6. 登録を完了する

入力チェック:

| 項目 | チェック |
| --- | --- |
| 確認コード | 必須 |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API03 | 確認コードを確かめ、登録を完了する | メールアドレス、確認コード |

画面表示制御:

- 確認コードが違う・期限切れの場合は、確認コードの欄の下にエラーを表示する
- 成功したら [UIS09](../UIS09/README.md) へ遷移する
- [UIS03](../UIS03/README.md) で Google がメールアドレスを確認済みとしていない人の確認コードも、この表示を使う

### 7. 確認コードを送り直す

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API04 | 確認コードを送り直す | メールアドレス |

画面表示制御:

- 登録済みかどうかで表示を変えない
