## 概要

機能目的:

- サーバーの障害で表示できないことを伝え、時間をおいて試してもらう

機能概要:

- 障害が起きたことの表示
- 再読み込み・ホームへの導線

関連する機能：なし

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | |
| 2 | 再読み込み | ボタン押下 | 開こうとしたページを読み込み直す |
| 3 | ホームへ戻る | ボタン押下 | [UIS09](../UIS09/README.md) へ遷移 |

### 1. 初期表示

起動パラメータ：なし

利用API：なし

画面表示制御:

- 「時間をおいて、もう一度お試しください。」を表示する
- エラーの番号（500）は画面に出さない

### 2. 再読み込み

開こうとしたページを読み込み直す。成功したら、そのページを表示する。
