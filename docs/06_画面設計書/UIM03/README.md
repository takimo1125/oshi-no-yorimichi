## 概要

機能目的:

- 自分の記録を削除する直前に、本当に削除するかを確かめる

機能概要:

- 削除する記録の表示
- 削除の実行

関連する機能：B-06

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 削除する記録を表示する |
| 2 | 削除する | ボタン押下 | 記録を削除し、[UIS15](../UIS15/README.md) へ遷移 |
| 3 | キャンセル | ボタン押下 | 削除せずにモーダルを閉じる |

## イベント詳細

### Figma の操作と遷移

共通ナビゲーションは [画面共通の動き](../README.md#全画面で共通の動き) を参照。表はリンクが設定された操作を示す。リンクのない操作の処理・未確定事項は後述する。

| 画面モデル | 操作 | 遷移先・状態 | 表示方法 |
| --- | --- | --- | --- |
| 全状態 | 削除する | [UIS15](../UIS15/README.md)（`diary`） | 画面へ遷移 |

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| post_id | 削除する記録の ID | |

画面表示制御:

- 削除する記録と、削除した記録は元に戻せないことを表示する。削除した記録を保管して元に戻す機能（ゴミ箱）は作らない

### 2. 削除する

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API31 | 記録を削除する | post_id |

画面表示制御:

- 削除に成功したら [UIS15](../UIS15/README.md) へ遷移する
- 削除した記録は、その記録を入れていた展示から外す。展示そのものは残す
- その記録から書き出した画像と、その記録を含む展示の書き出し済み PDF は、削除後はサービスから取得できなくする（機能索引の H-06 で初版に含めた範囲）

### 3. キャンセル

モーダルを閉じ、呼び出し元（[UIS12](../UIS12/README.md)・[UIS14](../UIS14/README.md)）へ戻る。編集中の内容は保つ。
