## 概要

機能目的:

- Google の認証を終えた人に、ユーザー名などを登録してもらい、登録を完了する

機能概要:

- 連携した Google アカウントのメールアドレスの表示（変更不可）
- ユーザー名・表示名・パスワードの入力
- 利用規約・プライバシーポリシーへの同意

関連する機能：A-01

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 連携した Google アカウントのメールアドレスを表示する |
| 2 | 登録を完了する | ボタン押下 | 入力を確かめて登録し、[UIS09](../UIS09/README.md) へ遷移 |
| 3 | 別のGoogleアカウントを使う | ボタン押下 | [UIS02](../UIS02/README.md) へ遷移 |
| 4 | 利用規約・プライバシーポリシー | リンク押下 | [UIM01](../UIM01/README.md) を起動 |

### 1. 初期表示

起動パラメータ：Google の認証結果（認証基盤から受け取る）

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API08 | 認証中の Google アカウントのメールアドレスを取得する | 認証結果 |
| API01 | 規約の現在の版を取得する | なし |

画面表示制御:

- メールアドレスは一部を伏せて表示する（例：`yori***@gmail.com`）
- 同意欄は未選択で始める
- 「仮登録」という表示は使わない

### 2. 登録を完了する

入力チェック:

| 項目 | チェック |
| --- | --- |
| ユーザー名 | 必須。3〜20 文字。半角の英小文字・数字・アンダースコア（_）だけ。大文字と小文字を区別せずに、ほかの利用者と重複させない |
| 表示名 | 任意。30 文字まで。あとから変更できる。空のときはユーザー名を表示する |
| パスワード | 必須。8 文字以上で、英字と数字を両方含む（認証基盤 Cognito のパスワードの条件で設定する） |
| パスワード（確認用） | 必須。パスワードと一致すること |
| 同意欄 | 選択していること |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API09 | 利用者を登録し、最新の利用規約・プライバシーポリシーへの同意を記録する。Google のメールアドレスとパスワードでもログインできるようにする | ユーザー名、表示名、パスワード、同意した文書の版 |

画面表示制御:

- 入力チェックに通らない場合は、登録しない。項目ごとに理由を表示する
- 登録に成功したら [UIS09](../UIS09/README.md) へ遷移する
- Google で登録する人にもパスワードを決めてもらい、メールアドレスとパスワードでもログインできるようにする（[ADR-0027](../../12_ADR/0027-Googleで登録するときもパスワードを決めてもらう.md)）
- Google がメールアドレスを確認済みとしている場合は、確認コードを送らない。確認済みとしていない場合だけ確認コードを送り、入力が済むまではメールアドレスとパスワードではログインできない。確認コードの入力は [UIS04](../UIS04/README.md) の `signup_email_confirm` と同じ表示を使う
- ユーザー名が使われていた場合の表示は未確定

### 4. 利用規約・プライバシーポリシー

[UIM01](../UIM01/README.md) を起動する。入力中の内容は保ったまま開く。閉じても同意欄は選択しない。

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| document | `terms` または `privacy` | 表示する文書 |
| caller | `UIS03` | 閉じたときの戻り先 |
