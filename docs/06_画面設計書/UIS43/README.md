## 概要

機能目的:

- 自分の記録や展示から、Instagram のストーリーズに載せる縦長（9:16）の画像を作ってもらう

機能概要:

- 画像を作る前の確認（作成の依頼）
- 作成中の表示
- 完成した画像の端末への保存
- 作成に失敗した状態の表示と再依頼

関連する機能：E-04、F-05

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 書き出しの状態に合わせた表示にする |
| 2 | 画像をつくる | ボタン押下 | 画像の作成を依頼し、作成中の表示に切り替える |
| 3 | 画像を保存 | ボタン押下 | 完成した画像を端末に保存する |
| 4 | 通知を見る | ボタン押下 | [UIS30](../UIS30/README.md) へ遷移 |
| 5 | キャンセル・記録に戻る | ボタン押下 | Figma の表示例は [UIS14](../UIS14/README.md)（`post_detail`）へ遷移 |
| 6 | 対象のプレビュー・元になった記録 | 項目押下 | [UIS14](../UIS14/README.md)（`post_detail`）へ遷移 |
| 7 | もう一度書き出す | 操作実行 | 失敗した書き出しの再依頼を受け付ける |

### 1. 初期表示

起動パラメータ:

| Name | Value | Memo |
| --- | --- | --- |
| target_type | `post` または `exhibition` | 書き出す対象の種類 |
| target_id | 記録または展示の ID | |
| export_id | 書き出しの ID | 依頼受付後の状態確認・失敗後の再依頼・完成の通知から開く場合に使用する |

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API30・API64 | 書き出す対象の記録・展示を取得する | target_type、target_id |
| API79 | 書き出しの状態を取得する | export_id（渡されたときだけ） |

画面表示制御:

| 状態 | 表示 | 画面モデル |
| --- | --- | --- |
| 依頼の前 | 対象の記録・展示と、出力のサイズ（縦長 9:16）・「画像をつくる」 | `export_image_request` |
| 作成中 | 「完成すると通知でお知らせします。この画面を離れても作成は続きます。」・「通知を見る」 | `export_image_processing` |
| 完成 | 完成した画像・「画像を保存」 | `export_image_ready` |
| 失敗 | 「画像を作成できませんでした」・元の記録は残っていること・「もう一度書き出す」。対象の記録を削除した後は「対象が削除されたため、書き出せません」とし、「もう一度書き出す」を出さない（[共通の失敗表示と再依頼](../README.md#書き出しの失敗と再依頼)） | `export_image_failed` |

- 作成中の表示には、保存のボタンを出さない
- 書き出せるのは、本人の記録・展示だけ。ほかの利用者の記録・展示からは書き出せない。サーバー側でも本人以外からの依頼を受け付けない

### 2. 画像をつくる

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API78 | ストーリーズ用画像の作成を依頼する | target_type、target_id |

画面表示制御:

- 依頼を受け付けたら、作成中の表示に切り替える
- 画像は、書き出し用キューを通して ECS のワーカーが作る。完成したら通知用キューを通して通知が届く（F-05）

### 3. 画像を保存

完成した画像ファイルを端末に保存する。Instagram への投稿は本人が行い、このサービスからは自動で投稿しない。

### 5. キャンセル・記録に戻る

Figma の「キャンセル」「記録に戻る」のリンクは [UIS14](../UIS14/README.md)（`post_detail`）を示す。作成中に画面を離れても、作成は続く。展示から書き出した場合の戻り先を切り替える仕様は未確定。

### 7. もう一度書き出す

失敗した書き出しに対し、[共通の再依頼処理](../README.md#書き出しの失敗と再依頼) を行う。作成中・完成と区別し、再依頼は API80 で行い、失敗の表示は `export_image_failed`。
