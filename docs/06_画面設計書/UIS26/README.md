## 概要

機能目的:

- 新しい展示のタイトル・表紙・説明・公開範囲を決めてもらう

機能概要:

- 展示のタイトル・表紙・ひとことの入力
- 公開範囲の選択
- 展示に使う記録の選択への導線

関連する機能：E-01、E-02

## イベント概要

| No | イベント名 | イベント分類 | 処理説明 |
| --- | --- | --- | --- |
| 1 | 初期表示 | 初期表示 | 表紙の候補にする本人の写真を表示する |
| 2 | 表紙 | 項目押下 | 表紙にする写真を選ぶ |
| 3 | 記録を選ぶ | ボタン押下 | 入力した基本情報を保ち、[UIS27](../UIS27/README.md) へ遷移 |
| 4 | キャンセル | ボタン押下 | [UIS25](../UIS25/README.md) へ遷移 |

## イベント詳細

### Figma の操作と遷移

共通ナビゲーションは [画面共通の動き](../README.md#全画面で共通の動き) を参照。表はリンクが設定された操作を示す。リンクのない操作の処理・未確定事項は後述する。

| 画面モデル | 操作 | 遷移先・状態 | 表示方法 |
| --- | --- | --- | --- |
| 全状態 | 公開 | 同じ画面で選択した値を表示 | 選択状態の変更 |
| 全状態 | 非公開 | 同じ画面で選択した値を表示 | 選択状態の変更 |
| 全状態 | 記録を選ぶ | [UIS27](../UIS27/README.md)（`exhibition_entries`） | 画面へ遷移 |
| 全状態 | キャンセル | [UIS25](../UIS25/README.md)（`exhibitions`） | 画面へ遷移 |

### 1. 初期表示

起動パラメータ：なし。作成中の展示の `exhibition_id` は、この画面を開いたときに画面が決める（新規でも ID はある。保存前の ID）。入力した基本情報は、この `exhibition_id` をキーにして sessionStorage に持ち、[UIS27](../UIS27/README.md) から戻ったときはそこから復元する（[API 設計書の「画面間の入力の受け渡し」](../../07_API設計書/README.md#画面間の入力の受け渡し)）

利用API:

| ID | 処理 | Parameter |
| --- | --- | --- |
| API63 | 表紙の候補にする本人の写真を取得する | ページ送りの位置 |

画面表示制御:

- 初めて開くときは、公開範囲を公開・非公開のどちらも選ばない状態にする。[UIS27](../UIS27/README.md) から戻ったときは、入力済みの基本情報と公開範囲の選択を復元する

### 3. 記録を選ぶ

入力チェック:

| 項目 | チェック |
| --- | --- |
| 展示タイトル | 必須。40 文字まで |
| 表紙 | 任意。選ばなかったときは、最初の記録の写真を使う |
| ひとこと | 任意。200 文字まで |
| 公開範囲 | この画面では選ばせない。[UIS28](../UIS28/README.md) で保存するときに必須 |

画面表示制御:

- 基本情報を保ったまま [UIS27](../UIS27/README.md) へ遷移する
- この時点では展示を保存も公開もしない。初めて保存する処理は [UIS28 の「保存する」](../UIS28/README.md#3-保存する) にまとめる

### 4. キャンセル

作成手順から離れるため、未保存の入力がある場合は [共通の離脱確認](../README.md#未保存の入力と離脱) に従う。破棄して移動することを選んだら [UIS25](../UIS25/README.md) へ戻る。
