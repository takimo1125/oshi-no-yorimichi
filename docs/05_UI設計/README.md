# UI 設計

画面のデザインは Figma にあります。

- [推しのよりみち（改善案）（Figma）](https://www.figma.com/design/AUNEBoh9AdHbRHwHsyQaHJ)

全画面は、ページ「01 推しのよりみち・全画面（整理版）」に、カテゴリーごとに並べています。113 の画面モデルを PC とスマホで描いた 225 フレームです。フレームの名前は「画面モデルの識別子 日本語の画面名 / PC」のように付けています（例：`home ホーム / PC`）。各フレームの横には、その画面の説明を書いたフレーム（名前が「説明」で始まるもの）を置いています。

主要な利用の流れ（新規登録・ログイン・記録・みんなの記録・展示の作成・展示プラスの申し込み）は、ページ「02 主要な動線」に、PC の画面と矢印・分岐でまとめています。

画面設計書（[06_画面設計書](../06_画面設計書/README.md)）の各画面の先頭に、代表のフレームと全フレームへのリンクを置いています。

色・文字・部品の決まりは、life リポジトリ `03-ai-output/WebDev/2026-11-05-推しのよりみち-デザインシステム.md` にあります。
